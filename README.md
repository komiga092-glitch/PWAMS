# PWAMS

People Welfare Association Management System.

## Purpose

PWAMS is a web-based NGO management system for managing:

- Users and roles
- Beneficiaries
- Students
- Donors
- Aid requests
- Loans and repayments
- Revenue
- Reports
- Notifications
- Audit logs
- Offline synchronization

## Technology Stack

- Go
- Gin
- PostgreSQL
- GORM
- Templ
- HTMX
- Tailwind CSS
- PWA
